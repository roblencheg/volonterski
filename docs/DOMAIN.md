# volonterski.ru: GitHub Pages + REG.RU

1. В GitHub Settings → Pages выбрать Source: GitHub Actions.
2. В Custom domain установить volonterski.ru и Save. public/CNAME сам по себе не устанавливает домен при публикации через Actions.
3. В REG.RU открыть DNS домена. Менять записи у фактического DNS-провайдера, если NS не REG.RU. Сначала сохранить текущую зону и проверить, не привязана ли почта/MX к корневому имени.
4. У корня @ установить четыре A-записи:

| Тип | Имя | Значение |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | roblencheg.github.io. |

Удалить конфликтующие старые A/AAAA/ALIAS только у @ и старые записи только у www. Остальные поддомены, MX, TXT, NS не изменять. Если почта использует сам @ как MX/сервер, сначала обеспечить отдельное имя почтового сервера, иначе замена @ затронет почту. Для IPv6 можно добавить четыре AAAA из официальной документации GitHub; оставлять старые AAAA нельзя.

5. Дождаться DNS check и выдачи сертификата, включить Enforce HTTPS. Распространение DNS может занять до 24 часов.
6. В Actions запустить workflow вручную, если первоначальный деплой упал до включения Pages.
7. Проверить корень, www (редирект на корень), статью, тему, поиск, вложения и мобильную версию без VPN из целевой сети.

Рекомендуется также подтвердить владение доменом в GitHub Settings → Pages через выданную GitHub TXT-запись.

Официальные сведения: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

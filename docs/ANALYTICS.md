# Аналитика сайта

Сайт поддерживает **Umami Cloud** и **Microsoft Clarity** без отдельного сервера. Оба счётчика загружаются только после явного согласия посетителя. При отказе внешние запросы к этим сервисам не выполняются. Отзыв согласия перезагружает страницу, чтобы остановить сбор данных в текущей сессии.

## Настройка

1. Создайте сайт в [Umami](https://cloud.umami.is) и скопируйте **Website ID** (UUID).
2. Создайте проект в [Microsoft Clarity](https://clarity.microsoft.com) и скопируйте **Project ID**.
3. Откройте GitHub → `roblencheg/volonterski` → Settings → Secrets and variables → Actions → **Variables** и добавьте:
   - `UMAMI_WEBSITE_ID` — UUID сайта в Umami;
   - `CLARITY_PROJECT_ID` — ID проекта Clarity.
4. В Actions запустите workflow **Build and deploy journal** через `workflow_dispatch` либо сделайте коммит в `main`.
5. Откройте сайт в приватном окне, разрешите аналитику и проверьте сетевые запросы `cloud.umami.is/script.js` и `clarity.ms/tag/...`.

Обе переменные **публичные** и попадают в HTML. Никогда не записывайте в них API-ключи или секреты. Если оба ID не заданы, внешняя аналитика отключена.

Для локального запуска задайте `PUBLIC_UMAMI_WEBSITE_ID` и `PUBLIC_CLARITY_PROJECT_ID` в `.env` (без записи файла в Git). На production GitHub Actions передаёт их из variables.

## События Umami

| Событие | Что означает |
| --- | --- |
| `article_read_75` | Просмотрено 75% тела статьи |
| `article_read_100` | Достигнут конец тела статьи |
| `github_click` | Клик по ссылке github.com, свойство `repository` |
| `file_download` | Клик по файлу, свойство `filename` |
| `code_copy` | Кнопка копирования кода |
| `search_used` | Enter в поисковом поле (без отправки текста запроса) |
| `share_click` | Нажатие «Скопировать ссылку» |

Базовые просмотры и источники трафика считает сам Umami. События начинают отправляться только после согласия. Дочитывание считается по прокрутке, а не по фактическому времени чтения. Clarity может записывать взаимодействия со страницами: не размещайте на отслеживаемых страницах конфиденциальные сведения и проверьте настройки маскирования перед запуском.

## Настройки согласия

Выбор сохраняется в localStorage под ключом `volonterski-analytics-consent-v1`. Посетитель может изменить его по ссылке **«Настройки аналитики»** в футере. Текст поиска, введённые данные и содержимое статей не отправляются в свойства событий Umami.

## Проверка

```bash
npm ci
npm run build
npm run verify
```

При отсутствии ID убедитесь, что в Network не появляются запросы к Umami и Clarity. При отказе тоже не должно быть таких запросов. После согласия оба счётчика должны загрузиться. После отзыва согласия страница перезагружается, дальнейшая загрузка прекращается.

Установленные браузером блокировщики трекеров могут препятствовать сбору статистики; данные не являются полным учётом всех посетителей.
